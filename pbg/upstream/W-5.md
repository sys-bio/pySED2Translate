# viva-tellurium and viva-copasi: output times must be uniform

Repositories: viva-tellurium, viva-copasi (0.1.2).  Evidence: **read** (visible in `config_schema`).

`TelluriumUTCStep` takes `start_time`, `end_time`, `n_points`; `CopasiUTCStep` takes `time`, `n_points`.  There is no way to
ask for specific output times (a vector), logarithmic spacing, or a `duration`-plus-explicit-points schedule.

Expected: an optional `times` list in both steps (roadrunner `simulate(times=...)`; basico `run_time_course(values=...)`).

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.2.6; Linux (x86_64). Observed 2026-10-09.
