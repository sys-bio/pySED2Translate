# viva-tellurium: TelluriumUTCStep and TelluriumSteadyStateStep ignore tolerances and seed

Repository: vivarium-collective/viva-tellurium (0.1.2).  Evidence: **confirmed by running.**

## Summary
`TelluriumUTCStep` and `TelluriumSteadyStateStep` inherit `absolute_tolerance`, `relative_tolerance` and `seed` in their
`config_schema` (through `BaseTelluriumStep`), but `BaseTelluriumStep._tellurium_initialize()` never applies them to the
integrator.  `TelluriumProcess._build()` does apply them, so the same config key means different things in the process and
in the steps.  The integrator stays on roadrunner's defaults.

## Reproduction
```python
from process_bigraph import allocate_core
from viva_tellurium.processes import TelluriumUTCStep, TelluriumProcess
core = allocate_core()
ant = "model m; S1 = 1; S2 = 0; k = 0.5; J1: S1 -> S2; k*S1; end"
cfg = {'model': ant, 'absolute_tolerance': 1e-3, 'relative_tolerance': 1e-2}
step = TelluriumUTCStep(cfg, core=core); step.update({})
proc = TelluriumProcess(cfg, core=core); proc._build()
print(step._rr.integrator.absolute_tolerance, step._rr.integrator.relative_tolerance)   # 1e-12 1e-06
print(proc._rr.integrator.absolute_tolerance, proc._rr.integrator.relative_tolerance)   # 0.001 0.01
step = TelluriumUTCStep({'model': ant, 'integrator': 'gillespie', 'seed': 5}, core=core); step.update({})
print(step._rr.integrator.seed)                                                         # random, not 5
```

## Observed
Requested 1e-3 / 1e-2: the step's integrator had 1e-12 / 1e-6 (roadrunner defaults); the process had 1e-3 / 1e-2.
Requested Gillespie seed 5: the step's integrator had a random seed.

## Expected
The same tolerance and seed handling in the steps as in `TelluriumProcess`, for example by moving the integrator setup
from `TelluriumProcess._build()` into `BaseTelluriumStep._tellurium_initialize()` (or a shared helper).

## Why it matters
A user who sets a tolerance on a step gets results at a different accuracy than they asked for, without any message.
Reproducibility across simulators (comparing against other tools at stated tolerances) depends on it.

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.2.6; Linux (x86_64). Observed 2026-10-09.
