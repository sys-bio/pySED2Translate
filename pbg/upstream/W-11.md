# Feature request: a flux balance analysis wrapper for process-bigraph

Target: vivarium-collective (no existing repository found).  Evidence: absence of evidence (search of the organisation's
repositories and of the web on 2026-10-09; not proof).

There is no wrapper in the viva-* family for flux balance analysis (for example a Step around COBRApy, which reads SBML-FBC
models: `cobra.io.read_sbml_model`, `model.optimize()`, `solution.fluxes`).  A wrapper would give a simulation experiment with a
flux balance analysis task (SED2 `fluxBalanceAnalysis`) a community implementation to run on, as the Tellurium and COPASI wrappers
do for ODE time courses.

A useful shape: config `model_file`, `objective` (reaction id or None for the model's own), `bounds` (map of reaction id to
[lower, upper]) and `solver`; outputs `fluxes` (`overwrite[map[float]]`), `objective_value` (`overwrite[float]`) and `status`;
and an `infeasible` outcome that is an error, not a zero.

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.5.3; Linux (x86_64). Observed 2026-10-09.
