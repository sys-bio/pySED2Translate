# Feature request: an OpenCOR / CellML wrapper for process-bigraph

Target: vivarium-collective (no existing repository found).  Evidence: absence of evidence (search of the organisation's
repositories and of the web; not proof).

There is no wrapper for CellML models or for OpenCOR / libOpenCOR in the viva-* family.  Wrapping libOpenCOR would cover
CellML and, through conversion, SBML models, and would make the same simulation experiment runnable on three independent
simulators.

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.2.6; Linux (x86_64). Observed 2026-10-09.
