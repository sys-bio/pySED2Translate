# viva-copasi: a model without species cannot be loaded

Repository: vivarium-collective/viva-copasi (0.1.2).  Evidence: **confirmed by running.**

## Summary
`BaseCopasi.interpret_sbml()` does `spec_df = get_species(model=self.dm)` and then `spec_df["sbml_id"]`.  For a model with no
species (a model made of parameters and rate rules, which is a valid ODE model) basico's `get_species` returns `None`, and the
step fails with `TypeError: 'NoneType' object is not subscriptable`.  `TelluriumUTCStep` runs the same model and returns the rate-rule
variable as a trajectory.

## Reproduction
`np.xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<sbml xmlns="http://www.sbml.org/sbml/level3/version2/core" level="3" version="2">
  <model id="m">
    <listOfParameters><parameter id="y" value="5" constant="false"/></listOfParameters>
    <listOfRules><rateRule variable="y"><math xmlns="http://www.w3.org/1998/Math/MathML"><cn>3</cn></math></rateRule></listOfRules>
  </model>
</sbml>
```
```python
from process_bigraph import allocate_core
from viva_copasi.processes import CopasiUTCStep
CopasiUTCStep({"model_source": "np.xml", "time": 1.0, "n_points": 3}, core=allocate_core())
#   File ".../viva_copasi/processes.py", line 117, in interpret_sbml
#     self.species_ids = spec_df["sbml_id"].tolist()
# TypeError: 'NoneType' object is not subscriptable
```

## Expected
Treat "no species" as an empty list (and report the parameters or compartments the model's rules drive, or say that they cannot
be reported).

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.5.3; Linux (x86_64). Observed 2026-10-09.
