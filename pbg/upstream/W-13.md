# viva-tellurium and viva-copasi: a COPASI step after a Tellurium step in one process crashes the interpreter

Repositories: viva-copasi, viva-tellurium (0.1.2); the crash is inside basico / libcombine.  Evidence: **confirmed by running.**

## Summary
When a `TelluriumUTCStep` has run in a process (importing tellurium's libroadrunner, libsbml and libcombine), building a
`CopasiUTCStep` in the same process ends in a segmentation fault (exit status 139) in `basico.model_info.get_reaction_mapping`,
called from `viva_copasi.processes.BaseCopasi.interpret_sbml` (`get_reactions`).  The other order (COPASI first, then Tellurium)
works, and importing tellurium and basico together works as long as `get_reactions` is not called afterwards.

## Reproduction
`decay.xml`: any one-species SBML model.
```python
from process_bigraph import allocate_core
from viva_tellurium.processes import TelluriumUTCStep
from viva_copasi.processes import CopasiUTCStep
core = allocate_core()
t = TelluriumUTCStep({"model_file": "decay.xml", "model_format": "sbml", "end_time": 1.0, "n_points": 3}, core=core)
print("tellurium", t.update({})["time_series"], flush=True)
c = CopasiUTCStep({"model_source": "decay.xml", "time": 1.0, "n_points": 3}, core=core)     # Segmentation fault
```
With `python -X faulthandler` the last frames are `libcombine/__init__.py: __next__`, `basico/model_info.py: get_reaction_mapping`,
`basico/model_info.py: get_reactions`, `viva_copasi/processes.py: interpret_sbml`.

## Why it matters
A composite with both simulators (a co-simulation of a Tellurium model and a COPASI model, or one experiment run on both) cannot
be loaded in one process.  Which package is at fault (basico, libcombine as shipped with tellurium, or an ABI clash of the
libsbml builds the two bring) is not established; the draft is for whoever can tell.

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.5.3, tellurium 2.2.13.1 (libroadrunner 2.10.0),
copasi-basico 0.87, python-copasi 4.48.309; Linux (x86_64). Observed 2026-10-09.
