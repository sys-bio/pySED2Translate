# viva-copasi: model_source accepts only a path or URL, not SBML text

Repository: vivarium-collective/viva-copasi (0.1.2).  Evidence: **confirmed by running.**

## Reproduction
```python
from process_bigraph import allocate_core
from viva_copasi.processes import CopasiUTCStep
core = allocate_core()
CopasiUTCStep({'model_source': open('decay.xml').read(), 'time': 5.0, 'n_points': 6}, core=core)
# FileNotFoundError: COPASI/SBML model not found: model_source='<?xml version="1.0" ...
```

## Expected
Either accept SBML text in `model_source` (as viva-tellurium accepts `model` plus `model_format`), or document that a path is
required.  Models produced at run time (after a parameter change) can then be passed without writing a temporary file.

Environment: Python 3.13, process-bigraph 1.8.5, bigraph-schema 1.7.0, numpy 2.5.3; Linux (x86_64). Observed 2026-10-09.
